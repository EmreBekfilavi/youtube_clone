# 🎥 YouTube Clone (React)

---

## EN English

This project is a frontend application developed using **React**, aiming to replicate a YouTube-like video browsing and viewing experience. It follows a **component-based architecture** and leverages modern **JavaScript (ES6+)** features.

### 📌 Features

* YouTube-inspired user interface
* Video listing and card-based layout
* Search functionality
* Component-based React architecture
* Responsive design
* Ready for video API integrations

### 🛠️ Technologies

* ⚛️ React (Create React App)
* 💻 JavaScript (ES6+)
* 📦 npm
* 🎨 HTML & CSS

### 🚀 Local Setup

```bash
git clone https://github.com/EmreBekfilavi/youtube_clone.git
cd youtube_clone
npm install
npm start
```

The application runs by default at `http://localhost:3000`.

✨ This project is suitable for learning purposes and frontend portfolio usage.
